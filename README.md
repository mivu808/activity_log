# くらしログ — 生活・活動記録アプリ

読書・映画・勉強・音楽・趣味など、「今日は実際に何分、何をしたか」を記録するための
個人用アプリです。iPhoneのホーム画面に追加してPWA（アプリのように動くWebアプリ）として使えます。

---

## 1. ファイル構成

```
life-log-app/
├── index.html              アプリ本体（ホーム／記録／履歴／分析の4画面）
├── style.css                デザイン（配色・レイアウト・ダークモード）
├── app.js                   ロジック（保存・集計・グラフ描画など）
├── manifest.json             PWA設定（アプリ名・アイコン・起動方法）
├── service-worker.js         オフライン動作のためのキャッシュ処理
├── icons/
│   ├── icon-192.png          ホーム画面アイコン（小）
│   ├── icon-512.png          ホーム画面アイコン（大）
│   ├── icon-512-maskable.png Android用の余白付きアイコン
│   ├── apple-touch-icon.png  iOS用アイコン（180×180・背景透過なし）
│   └── favicon-32.png        ブラウザタブ用アイコン
└── README.md                 このファイル
```

## 2. 各ファイルの役割

- **index.html**：画面のHTML構造。4つの `<section class="screen">` を
  JavaScriptで切り替えて、ページ遷移なしの1ページアプリとして動きます。
- **style.css**：「静かな生活記録ノート」を意識した配色・余白・タイポグラフィ。
  `prefers-color-scheme` と設定画面のトグルでダークモードに対応し、
  `env(safe-area-inset-*)` でノッチ・ホームバー領域を避けます。
- **app.js**：
  - データはすべて `localStorage` に保存（外部通信なし）
  - 記録の追加・編集・削除
  - カテゴリの追加・編集・削除（使用中のカテゴリは削除不可）
  - 今日／週／月の集計、グラフ描画
  - JSONバックアップの書き出し・復元
- **manifest.json**：ホーム画面に追加した際のアプリ名・アイコン・
  スタンドアロン表示（URLバーを隠す）を指定します。
- **service-worker.js**：初回アクセス時にアプリ本体をキャッシュし、
  電波が無い場所でも起動・記録できるようにします。

## 3. 起動方法（パソコンで確認する場合）

ブラウザは `file://` からだとService Workerが動かないことがあるため、
簡易サーバーを立てて確認してください。

```bash
cd life-log-app
python3 -m http.server 8000
```

その後、パソコンのブラウザで `http://localhost:8000` を開きます。
（スマホの実機確認は手順4のGitHub Pages公開後がおすすめです。）

## 4. GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成します（例：`life-log-app`）。
2. このフォルダの中身一式（`index.html` や `icons/` フォルダごと）を
   リポジトリの**ルート**にそのままアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. 「Source」で **Deploy from a branch** を選び、ブランチを `main`、
   フォルダを `/ (root)` にして保存します。
5. 数分待つと、`https://ユーザー名.github.io/リポジトリ名/` で
   アプリにアクセスできるようになります（GitHub PagesはHTTPS配信なので、
   Service Workerもそのまま動作します）。

> `manifest.json` や `service-worker.js` の参照パスはすべて相対パス（`./`）にしてあるので、
> リポジトリ名がURLに含まれるサブパス構成でもそのまま動きます。

## 5. iPhoneでPWAとして使う方法

1. iPhoneのSafariで、公開したURL（`https://.../`）を開きます。
   ※ Chromeなど他ブラウザではホーム画面追加時にアプリらしく動かないため、
   **必ずSafariで開いてください。**
2. 画面下の「共有」ボタン（四角から矢印が上に伸びたアイコン）をタップします。
3. メニューから「**ホーム画面に追加**」を選びます。
4. 名前を確認して「追加」をタップします。
5. ホーム画面に追加されたアイコンから起動すると、Safariの
   URLバーなどが表示されず、独立したアプリのように全画面で動作します。

一度開いておけば、そのあとは機内モードなどオフラインの状態でも
記録・閲覧・集計ができます（データは端末内にのみ保存されます）。

### データの引き継ぎ・バックアップ

- 分析画面右上の「設定」→「データを書き出す（JSON）」で
  記録・カテゴリをまとめたJSONファイルをダウンロードできます。
- 機種変更時などは、新しい端末で同じくSafariからアプリを開き、
  「設定」→「JSONから復元する」で書き出したファイルを選ぶと復元されます。

## 6. PWAとしての動作確認チェックリスト

GitHub PagesでHTTPS公開したうえで、以下を確認済みです。

- **manifest.json**：`display: "standalone"`、日本語名、アイコン3種
  （192／512／maskable）を指定。相対パス（`./`）なのでサブパス配信でも解決可能。
- **service-worker.js**：`install` 時にアプリ本体一式をキャッシュし、
  `fetch` はキャッシュ優先＋オフライン時のフォールバックで、
  電波が無くても `index.html` が表示されるようにしてある。
  `activate` 時に古いキャッシュを削除し、更新時に古い表示が残らないようにしている。
- **アイコン**：`apple-touch-icon.png`（180×180・背景透過なし）を
  `<link rel="apple-touch-icon">` で指定。iOSのホーム画面・スタンドアロン表示の
  タイトルバーで正しいアイコンが使われる。
- **Safe Area**：`viewport-fit=cover` と `env(safe-area-inset-top/bottom)` を
  ヘッダー・下部ナビゲーションに適用し、ノッチやホームインジケーターの
  下にボタンが隠れないようにしてある。
- **standalone表示**：`apple-mobile-web-app-capable` と
  `apple-mobile-web-app-status-bar-style` を設定し、ホーム画面追加後は
  SafariのURLバー・ツールバーが表示されない全画面表示になる。
- **LocalStorageの動作**：記録・カテゴリ・テーマ・直近使用カテゴリを
  すべて `localStorage` に永続化。ページを閉じても、機内モードでも
  データは端末内に残る（IndexedDBではなくLocalStorageのみで完結する設計）。

コードの静的チェック（JS構文チェック・日付/集計ロジックの単体テスト）は
実施済みです。実機でのタップ操作やアニメーションの見た目は、
公開後にご自身のiPhoneで一度ご確認いただくのがもっとも確実です。
